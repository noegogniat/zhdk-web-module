Overlay

The caption belongs on the picture, not under it. Scroll this column and keep the title in view. The work number should not travel with the page.

An element taken out of flow still needs a containing block. The nearest positioned ancestor is the one that counts, not necessarily the parent in the HTML.

Fixed looks at the viewport. Sticky looks at the nearest scrollport and only moves when it has to. Try both, then decide which one the reference is using for each piece.

Keep the type in the same register as the rest of the site: uppercase title, hairline figure, caption the same size as the body.
